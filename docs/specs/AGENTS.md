# The specs

Each spec here is a goal's spec: its page is `llm-wiki/general/pages/ideas/<the spec's file name>`. A new spec is written with
its goal's page in the same commit (`uvx --from git+https://github.com/orkCraft/orkBoard orkboard import --goals docs/specs`
lays it; then give it its party). The Board's rules are Orkboard's block in the root `AGENTS.md`.
